Key Capabilities

⚡

Lowercase Phonetic Typing

Type Bangla naturally using plain lowercase English letters. A bundled frequency-ranked dictionary disambiguates phonetic spellings (such as acho → আছো) so you get the exact word you intended without tedious key hunting.

🔒

100% Offline & Private

Built without the Android INTERNET permission. The app makes zero network connections, has no analytics beacons or advertising trackers, and cannot transmit typed text off your device under any condition.

📚

Bundled Bengali Dictionary

High-quality suggestions derived from the openly licensed (CC0) AI4Bharat IndicCorp v2 Bengali corpus. All word counts and vocabulary tables are pre-compiled into the APK for instant lookup with zero network latency.

🛡️

Automatic Sensitive Field Guard

Whenever your cursor enters a password, e-mail, or URL input field, Bangla Keyboard automatically transitions to a standard English layout and suppresses suggestion caching to guarantee maximum privacy.

🌐

Fast Bangla ⇄ English Switching

Switch fluidly between Bangla phonetic mode and standard English QWERTY with a single tap. Features dedicated symbol layouts, native Bangla digits (১, ২, ৩...), and complete emoji picker integration.

🚀

Native Kotlin Architecture

Engineered with modern Android best practices using native Kotlin and Android's InputMethodService. Highly lightweight, responsive, and battery-friendly with negligible CPU and memory footprints.

🛠️ Setup Instructions

Enabling Bangla Keyboard on your Android device takes less than a minute:

1. Install

Install Bangla Keyboard from the Google Play Store on any device running Android 8.0 (Oreo) or higher.

2. Enable Keyboard

Go to Settings → System → Languages & Input → On-screen keyboard → Manage on-screen keyboards and toggle Bangla Keyboard on.

3. Choose Input Method

Tap on any text area, select the small keyboard icon at the bottom of the navigation bar, and select Bangla Keyboard.

4. Start Typing

Type phonetically using plain lowercase characters or toggle instantly to English whenever needed.

🛡️ Privacy Commitment

Read Full Privacy Policy →

Bangla Keyboard is designed with privacy as the default. Everything you type is processed purely on your device hardware:

  • No Network Access: The app does not request or possess the Android internet permission; it is technically incapable of sending data out.
  • No Keystroke Logging: Typed text, suggestions, and selections are never saved to storage or sent to any server.
  • No Analytics or Ads: Zero third-party SDKs, telemetry beacons, or advertising frameworks.
  • No Cloud Sync: Automatic cloud backup of keyboard state is explicitly disabled.

For Google Play Console verification and detailed legal statements, please review our official Privacy Policy.

❓ Support & Frequently Asked Questions

What is this website URL for?

This page (https://hissain.github.io/android/bangla-keyboard) serves as the official App Website and documentation hub for Bangla Keyboard (com.infomity.banglakeyboard) on the Google Play Store and other distribution channels.

Why does Android show a warning when enabling the keyboard?

Android displays a standard operating system alert ("This input method may be able to collect all the text you type...") for every newly activated third-party keyboard. Bangla Keyboard has no internet permission and does not record or store your inputs.

Where do the phonetic suggestions come from?

Suggestions come from an offline word list pre-packaged inside the application, derived from the openly licensed (CC0) AI4Bharat IndicCorp v2 Bengali corpus. No online lookups occur.

How can I report a bug or request an enhancement?

For bug reports, vocabulary suggestions, or inquiries, please contact the developer through the GitHub or LinkedIn profiles linked in the footer.
