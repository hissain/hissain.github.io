Privacy Policy & Transparency Report

Official User Data Disclosure for Bangla Keyboard for Android

App: Bangla Keyboard Package: com.infomity.banglakeyboard Publisher: Infomity Network: Zero Permission

Summary & Core Guarantee

Bangla Keyboard operates entirely offline on your device hardware. It does not collect, record, transmit, or monetize your personal information, credentials, keystrokes, or communications. The application requests zero network permissions and is technically incapable of sending data off your device.

1. What Happens to What You Type (100% Local Processing)

Bangla Keyboard was engineered with a strict privacy-by-design architecture:

  • Volatile Memory Only: All keystrokes, phonetic transliterations, and candidate predictions are processed exclusively in volatile device RAM while the keyboard is actively on screen.
  • No Network Transmission: The application does not declare or request the Android android.permission.INTERNET permission. It possesses no network sockets and cannot transmit data to our servers or any third-party infrastructure.
  • No Keystroke Logging: Typed text, selected suggestions, and vocabulary inputs are never written to disk, persistent storage, or diagnostic files. When the keyboard collapses, temporary suggestion states are cleared.

2. Sensitive Input Fields (Passwords, Emails & URLs)

Whenever your cursor enters a sensitive text field (such as a password, PIN, e-mail address, or browser URL bar), Bangla Keyboard automatically detects the InputType:

  • The keyboard automatically transitions to a standard English layout.
  • Word suggestion caching, dictionary candidate ranking, and personalization are completely suppressed in sensitive fields.

3. Operating System Permissions Breakdown

Bangla Keyboard requests only the minimum operating system permissions strictly required for Input Method Editor (IME) functionality:

  • Input Method Service (BIND_INPUT_METHOD): Standard operating system permission required for any application to provide an on-screen keyboard.
  • Vibrate (android.permission.VIBRATE): Used solely to provide optional haptic touch feedback when you tap keyboard keys. This can be toggled on or off at any time.

4. Local App Storage & Settings

The application stores only three non-identifiable user preferences locally in Android private sandbox storage (SharedPreferences):

  • Whether Bengali digits are preferred over Arabic numerals.
  • Whether key haptic vibration is active.
  • The last selected input mode (Bangla Phonetic or English).

This configuration data never leaves your device and is permanently deleted when you uninstall the app. Android automatic cloud backup of application data is explicitly disabled (android:allowBackup="false").

5. Offline Dictionary & Word List

All word suggestions originate from a pre-compiled, offline statistical word frequency dictionary bundled directly into the APK binary:

  • The vocabulary list is derived from the openly licensed (CC0) AI4Bharat IndicCorp v2 Bengali corpus.
  • Only derived mathematical word frequency counts are bundled—no raw source texts are stored or accessed.
  • No network lookups or cloud queries are executed to generate suggestions.

6. Information We Do NOT Collect

To ensure total transparency with Google Play Developer Policies:

  • No Personal Data: We do not collect names, emails, phone numbers, or account details.
  • No Device Identifiers: We do not read IMEI, Android ID, Advertising ID (AAID), MAC address, or serial numbers.
  • No Location Data: Zero GPS, Wi-Fi, or cellular network location tracking.
  • No Device Content: Zero access to contacts, photos, microphone, storage, or external files.
  • No Telemetry or Crash Reports: The app contains zero analytics frameworks (e.g. Firebase Analytics, Mixpanel) and zero crash reporting beacons.

7. Third-Party Code & Advertising

Bangla Keyboard is 100% ad-free and tracking-free. It does not integrate Google AdMob, Unity Ads, Facebook Audience Network, or any programmatic advertising SDKs. No user data is sold, rented, or shared with third parties under any circumstances.

8. Children's Privacy

Our application does not collect any personal data from anyone, including children under the age of 13. It complies fully with the Children's Online Privacy Protection Act (COPPA) and Google Play Families Policies.

9. Android Security Dialog Clarification

When activating any third-party keyboard on Android, the operating system presents an obligatory system warning dialog: "This input method may be able to collect all the text you type, including personal data like passwords and credit card numbers...".

This alert is generated automatically by Android for every newly enabled IME. Because Bangla Keyboard does not have internet access, it is technically incapable of sending any of your inputs over the network.
