AndroidSemanticSearch

hissain / AndroidSemanticSearch
Zero-latency offline neural vector search & retrieval on mobile

A minimalistic Android application demonstrating local, high-speed semantic search without cloud dependencies. Integrates the MiniLM-L6-V2 sentence embedding model, TensorFlow Lite, ObjectBox vector database, and Apache Lucene KNN to deliver context-aware retrieval directly on the device.

  • On-device text embeddings via TensorFlow Lite & Bert vocabulary tokenizer
  • Embedded vector store leveraging ObjectBox HNSW & Lucene KNN indexing
  • 100% private execution with sub-30ms similarity query latency
  • Clean MVVM architecture with Kotlin Coroutines and Flow
Keywords — Kotlin, TensorFlow Lite, ObjectBox, Lucene KNN, Vector Search

Signal Processing & DSP Library & Studio

jSciPy Android Studio

Scientific Computing on Android
Interactive DSP filter studio & scientific computing workbench

Mobile interactive testbed built on the jSciPy scientific library. Empowers mobile engineers and biomedical researchers to design digital filters (Butterworth, Chebyshev, Bessel), compute real-time FFT frequency spectrums, analyze Power Spectral Density (PSD), and detect waveform peaks.

  • Zero-dependency native JVM/Android scientific mathematics engine
  • Live frequency response graphing for low-pass, high-pass, and bandpass filters
  • High-throughput peak detection algorithms for ECG/PPG biomedical waveforms
  • Runge-Kutta (RK4) differential equation solver and numerical calculus
Keywords — Java, Kotlin, jSciPy, FFT, Signal Processing, Filters

PulseTrack BLE

Wearable Biometrics Companion
Real-time wearable physiological telemetry & continuous HRV analyzer

Specialized companion utility for BLE health sensors and custom biometric strap prototypes. Captures raw photoplethysmography (PPG) and motion data, computing Heart Rate Variability (HRV - SDNN, RMSSD, pNN50) metrics and stress indicators in real-time on device.

  • Low-power background BLE GATT auto-reconnection & packet streaming
  • Motion artifact mitigation with real-time systolic peak extraction
  • Autonomous HRV metric calculation and Poincaré plot rendering
  • Encrypted local biometric database storage via Room & SQLCipher
Keywords — Kotlin, BLE GATT, Jetpack Compose, Room, HRV, Wearables

ChronoSync DLMO

Circadian Rhythm Tracking
Circadian phase estimation & physiological light exposure tracking

Mobile platform translating clinical research on Dim Light Melatonin Onset (DLMO) estimation into a practical user utility. Combines continuous ambient illuminance sensing (lux), actigraphy motion patterns, and behavioral inputs to estimate internal biological clock phase alignment.

  • Ambient light spectral dosimetry & circadian stimulus (CS) accumulation
  • Multi-day wearable actigraphy integration for sleep-wake rhythm modeling
  • Personalized phase response curve (PRC) recommendations for shift workers
  • Based on clinical wearable sensing methodologies developed with MIT/Caltech
Keywords — Kotlin, SensorManager, Circadian Biology, WorkManager, ML

Signal Processing & DSP Alpha Build

AudioSense NDK

Low-Latency Acoustic Analyzer
Sub-10ms buffer latency acoustic spectrum & waterfall visualizer

A high-performance audio engine engineered with modern C++20 and the Android NDK. Utilizes Google Oboe and AAudio to record uncompressed microphone audio at minimal latency, executing Short-Time Fourier Transforms (STFT) rendered via custom OpenGL ES fragment shaders.

  • Native real-time audio pipeline powered by Google Oboe & AAudio
  • Accelerated STFT with selectable Hamming, Hann, and Blackman windows
  • 60 FPS continuous waterfall spectrogram rendering via OpenGL ES
  • Calibrated dB SPL metering, harmonic distortion analysis, and pitch tracking
Keywords — C++20, NDK, Oboe, AAudio, OpenGL ES, JNI, Audio DSP

SensorForge Pro

Hardware Diagnostics & Logger
High-frequency telemetry logger & sensor fusion calibration bench

Comprehensive engineering tool for mobile developers, roboticists, and sensor researchers. Provides uncalibrated and fused telemetry across all hardware sensors (accelerometers, gyroscopes, magnetometers, barometer) with real-time multi-channel plotting and high-speed CSV export.

  • Unrestricted sampling frequencies up to SENSOR_DELAY_FASTEST (200Hz+)
  • Live comparison of Raw vs. Complementary vs. Kalman-filtered sensor fusion
  • Synchronized high-throughput streaming to CSV and Apache Parquet
  • Real-time 3D device orientation visualizer with Quaternion angles
Keywords — Kotlin, Jetpack Compose, Sensor HAL, Sensor Fusion, Logging
